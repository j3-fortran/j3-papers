1. Introduction
The module procedure PROCEDURE_NAME is new in Fortran 2028, and there
are a few typos in the description of the procedure.

2. Edits
17.10.2.29 PROCEDURE_NAME ([CONTEXT])

[551:5+] Add a new bullet to describe bolded or
"**or** introduces a mutually exclusive alternative;"

[551:11] NAME= clause should be NAME= specifier to be consistent with use
elsewhere in the standard (ex C806)
Replace "clause" with "specifier"

[551:11] To be consistent, needs a colon at the end of the case phrase
Append a ":" after the word "format"

[551:12] This case is when a subprogram with binding-name exists, and should
read
module-name[/submodule-name]:subprogram-name=binding-name

[551:15] One bracket is slightly misplaced, as cannot have
internal-subprogram-name without a subprogram name
module-name[/submodule-name]:[subprogram-name][.internal-subprogram-name]
Move the right bracket after "subprogram-name" to the end of the line as:
module-name[/submodule-name]:[subprogram-name[.internal-subprogram-name]]

[551:25] Using "enclosing scope unit" seems too broad
Replace "enclosing scope unit" with "innermost scoping unit that contains
the templated subprogram or TEMPLATE construct".
