Fortran-lang/LFortran Liaison Report
====================================

Updates in the time frame October 16, 2023 to October 20, 2026.

Fortran-lang
------------

URL: https://fortran-lang.org/

* Fortran-lang became a NumFOCUS fiscally sponsored project
  (April 2024)
* Google Summer of Code: 11 projects, all completed (3 in 2024, 4 in
  2025, 4 in 2026); 9 of them for LFortran (intrinsics, OpenMP,
  compiling stdlib and fpm, coarrays, MLIR backend, third-party codes)
* FortranCon 2025 held online, November 4-5, 2025 (keynote: John Reid)
* Fortran newsletter revived in February 2026
* UK: "Back to the Fortran Future" workshops (2024-2026) and the new
  FortranFuture EPSRC Network+ (about 25 partner institutions)
* "Celebrating 70 years of Fortran" event planned for December 1, 2026
  in Manchester, UK (keynote: Damian Rouson)
* Fortran entered the TIOBE index top 10 in April 2024, for the first
  time since 2002
* Fortran Discourse: 2,238 registered users, 67,959 posts
* Fortran Standard Library (stdlib):
  - v0.4.0 (March 2024) through v0.8.1 (January 2026)
  - new linear algebra module (stdlib_linalg): solve, lstsq, det, SVD,
    eigenvalues, inverse, Cholesky, QR, Schur, norms, matrix
    exponential, iterative solvers; BLAS/LAPACK backends
  - sparse matrices, subprocess and filesystem modules
  - 233 merged pull requests by 49 authors since October 2023
* Fortran Package Manager (fpm):
  - v0.10.0 (January 2024) through v0.13.0 (February 2026)
  - shared and static libraries, compile_commands.json export,
    metapackages (BLAS, HDF5, NetCDF, MPI), manifest features and
    profiles, first-class LLVM Flang support
  - 137 merged pull requests by 27 authors since October 2023
* fortls (language server) v3.0.0 (May 2024); VS Code Modern Fortran
  extension v4.0.0 (January 2026); fprettify joined fortran-lang

LFortran
--------

URL: https://lfortran.org/

* Since October 16, 2023:
  * 138 contributors
  * about 16,500 commits
  * 5,345 merged pull requests
  * releases v0.30.0 through v0.67.0
* LFortran now compiles dozens of third-party codes; milestones
  announced on the blog:
  - dftatom (October 2023)
  - 60% of SciPy (January 2024)
  - Fortran stdlib (April 2024)
  - SNAP (August 2024)
  - PRIMA (March 2025)
  - POT3D (March 2025)
  - Reference LAPACK (February 2026)
  - fpm (February 2026)
  The CI also builds Caffeine, FIATS, Formal, Julienne, neural-fortran,
  toml-f and others on every update of the main branch.
* LFortran is still in alpha. It will be declared beta when almost any
  third-party code is expected to compile and work.
* All intrinsic procedures of the standard are implemented
* Fortran 2023: --std=f23 mode, conditional expressions, enumeration
  types
* F202Y generics (TEMPLATE, REQUIREMENT, INSTANTIATE) are fully
  implemented, following the J3 generics subgroup papers
* Prototype of the "Traits for Fortran" proposal
  (https://github.com/difference-scheme/Traits-for-Fortran) in the
  traits_05 branch of https://github.com/certik/lfortran
* OpenMP directives and DO CONCURRENT
* GPU offloading of DO CONCURRENT and OpenMP loops (Apple Metal, CUDA):
  - FIATS and Formal fully offload and run on Apple GPUs
  - Formal also fully offloads on NVIDIA GPUs, with high performance
* Coarrays via PRIF, using the Caffeine runtime
* Separate compilation of modules and submodules
* LFortran runs in the browser in a JupyterLite notebook (no install,
  no server); see "From Punch Cards to the Browser: Fortran Comes to
  JupyterLite" on the Jupyter blog (https://blog.jupyter.org/,
  October 1, 2026)
* Language server and VS Code client, WebAssembly backend, MLIR
  backend
* Blog: https://lfortran.org/blog/
