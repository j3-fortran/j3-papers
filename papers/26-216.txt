QUESTION:
May the OPERATION function provided to REDUCE have an allocatable or
pointer result?

ANSWER:
No, it was not intended that the OPERATION fuction provided to REDUCE allow
an allocatable or pointer result.
An edit is provided to correct this oversight.

EDITS to 24-007:
[34:1+] clause 4.3.3 Fortran 2018 Compatibility
Insert the following paragraph:

"Fortran 2018 permitted the OPERATION argument to REDUCE have an allocatable
or pointer result; this document does not permit such usage."

[436:16] 16.9.1.73 REDUCE, para 3, OPERATION argument

Before "nonpolymorphic", insert:

 "nonallocatable, nonpointer, "

Such that the entire sentence reads:

 "Its result shall be a nonallocatable, nonpointer, nonpolymorphic scalar and
  have the same declared type and type parameters as ARRAY."
